# Dataset

This folder contains the datasets used for the Week 7 Delta Lake MERGE assignment.

## Files

- customer_master.csv
- customer_incremental.csv

## Description

customer_master.csv

The primary customer dataset containing customer information including personal details, membership type, and account status.

customer_incremental.csv

An incremental dataset containing new customer records and updates to existing customers. This dataset is used to demonstrate Delta Lake MERGE (UPSERT) operations.

Both datasets were generated specifically for this assignment.
